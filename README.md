# Darija App

A language learning app designed to help Moroccans abroad learn, relearn, and reconnect with Moroccan Darija.

The app teaches everyday Darija through short interactive lessons using both Arabic script and Latin transliteration. This method was chosen because many Moroccans abroad cannot read or write in Arabic.

Future plans include an Arabic script learning section and audio recordings to help users learn the pronunciation of Darija words and expressions.

## Live Demo

[View the Darija App](https://rumihoney.github.io/darija-app/)

## How It Works

1. The user chooses a learning unit.
2. Each unit introduces common Darija vocabulary and expressions.
3. Questions are presented in Arabic script and Latin transliteration.
4. The user selects an answer and receives immediate feedback.
5. Lessons progress from basic vocabulary to everyday Moroccan Darija.
