# Darija App

A language learning app in early development, created to help Moroccans abroad learn, relearn, and reconnect with Moroccan Darija.

The app is being developed around short interactive lessons using both Arabic script and Latin transliteration, making the content accessible to learners who may speak or understand Darija but cannot read Arabic.

Growing up abroad, I started forgetting Darija myself, so this project is also a way for me to reconnect with the language while applying what I have learned in linguistics and programming. Language attrition is a topic that deeply interests me, and I hope to explore it further through this project.

## Live Demo

[View the Darija App](https://rumihoney.github.io/darija-app/)

## How It Works

1. The user chooses a learning unit.
2. Each unit introduces common Darija vocabulary and expressions.
3. Questions are presented in Arabic script and Latin transliteration.
4. The user selects an answer and receives immediate feedback.
5. Lessons progress from basic vocabulary to everyday Moroccan Darija.
